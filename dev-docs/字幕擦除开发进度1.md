  关键实现要点

  1. 请求转换 (BuildRequestBody)：从 req.Metadata["video_url"] 读取，兼容字符串和嵌套 {"url":...} 两种形态；缺失/空/类型错时直接 400。
  2. 轮询 (FetchTask + ParseTaskResult)：以 status 字段为最终判定基准（不盲信 CII 的 success），running/completed/failed/未知 映射到平台 TaskStatus 与 Progress。
  3. 计费 (AdjustBillingOnComplete)：解析 task.Data 的 created_at/finished_at，通过 common.QuotaFromFloat 换算为积分；异常值（< 0 或 > 14400 秒）写 task.FailReason + common.SysError + logger.LogWarn，不污染计费。
  4. 路径注入防护 (normalizeTaskApiPath)：复用了 doubao 的相同模式——限制字符集、长度、点段、scheme 等。
  5. 响应转换 (ConvertToOpenAIVideo)：实现 OpenAIVideoConverter 接口，让 controller.RelayTaskFetch 走 OpenAIVideo 形态返回。
