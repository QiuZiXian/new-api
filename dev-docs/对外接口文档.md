> 面向调用方。覆盖视频生成（Seedance）、字幕擦除、素材/素材组、真人审核、对话补全。
>
> 所有接口均为 HTTP + JSON，统一 Bearer Token 鉴权。
>
> **本文档依据**：apifox 实测记录（`dev-docs/AI模型接口.md`）+ 后台源码实现
> （`controller/asset.go`、`router/video-router.go`、`relay/channel/task/*`）。
> 若你实测看到的响应结构与本文不同，请先翻到文末 [§9 版本差异说明](#9-版本差异说明比对实测与当前实现) 确认部署版本。

## 1. 快速开始

### Base URL

```
http://<your-host>:3000
```

### 鉴权

所有请求都必须在 Header 中携带 API Key：

```http
Authorization: Bearer sk-xxxxxxxxxxxxxxxx
```

缺失或无效会返回 `401`。

### 第一个请求

```bash
curl -X POST "http://<host>:3000/v1/chat/completions" \
  -H "Authorization: Bearer sk-xxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-opus-4-6",
    "messages": [{"role": "user", "content": "Hello!"}],
    "stream": false
  }'
```

## 2. 通用约定

### 2.1 响应格式

创建/查询类接口统一返回业务对象（本地归一化形态）：

```json
{
  "id": "group-20260907145308-xntbl",
  "name": "我的素材组",
  "description": "…",
  "group_type": "AIGC",
  "created_at": 1757000000,
  "updated_at": 1757000000
}
```

列表类接口：

```json
{
  "items": [ … ],
  "total": 1,
  "page_num": 1,
  "page_size": 20
}
```

> 时间戳为 **Unix 秒**（int64），不是 ISO8601 字符串。

### 2.2 错误格式

```json
{
  "error": {
    "code": "bad_request",
    "message": "name 不能为空",
    "type": "…"
  }
}
```

或（任务类接口）：

```json
{ "code": "invalid_response", "message": "…", "status_code": 500 }
```

HTTP 状态码语义：

| 状态码 | 含义 |
|---|---|
| 200 | 成功 |
| 400 | 请求参数错误（缺必填、类型不对、值非法） |
| 401 | 未鉴权 / token 无效 |
| 403 | 无权限（如跨用户访问他人素材） |
| 404 | 资源不存在 |
| 409 | 状态冲突（如素材组非空时删除） |
| 429 | 触发限流 |
| 500 | 服务内部错误 |
| 502/503 | 上游（仓山/方舟）异常或无可⽤渠道 |

### 2.3 分页

列表接口统一用 query 参数：

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `page_num` | int | 1 | 页码，从 1 开始；非法值回退 1 |
| `page_size` | int | 20 | 每页条数；上限 500 |
| `status` | string | 空 | 素材列表可按状态过滤，如 `Active` |

### 2.4 异步任务范式（重要）

视频生成、字幕擦除是**异步任务**，遵循「提交 → 拿 ID → 轮询 → 取结果」三步：

```
POST   /v1/videos/generations          → 返回任务对象（含 id）
GET    /v1/videos/{task_id}            → 查状态，直到 status 进入终态
GET    /v1/videos/{task_id}/content    → 下载成品（需要鉴权）
```

任务状态机：

```
queued ──▶ running ──▶ succeeded  ✅（此时 content.video_url 可用）
   │           │
   │           └────▶ failed      ❌（error.code / error.message）
   └──▶ cancelled（仅 queued 状态可取消）
        expired / expired（超时）
```

**轮询建议**：间隔 ≥ 5 秒，最长等待 10 分钟。视频生成通常 1–5 分钟。

### 3.5 计费单位换算

平台内部以 **quota（积分）** 结算，展示时换算为金额：

```
金额(元) = quota / QuotaPerUnit × USDExchangeRate
```

默认 `QuotaPerUnit=500`、`USDExchangeRate=7.3`，即 **1 quota ≈ ¥0.0146**。

调用方可通过 `GET /api/log/token?p=1&size=20`（用同一个 `sk-` token 鉴权）
查询每次请求的真实消耗：

```json
{
  "items": [{
    "model_name": "doubao-seedance-2.5",
    "quota": 517,
    "prompt_tokens": 0,
    "completion_tokens": 0,
    "use_time": 63,
    "created_at": 1757000000
  }]
}
```

## 4. 视频生成（Seedance）

### 4.1 创建视频任务

```http
POST /v1/video/generations
```

> 等价别名：`POST /v1/videos`（OpenAI 兼容形态）。
> ⚠️ `POST /v1/videos/generations`（复数）在当前版本**未注册**，实测返回 `404 Invalid URL`。
> 若客户端报 404，先检查是不是把路径写成了复数形式。

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `model` | string | 是 | 见 §3.1 |
| `prompt` | string | 是 | 文本提示词 |
| `content` | array | 否 | 多模态内容，见下 |
| `resolution` | string | 否 | `480p` / `720p` / `1080p` / `4k`，默认 `720p` |
| `ratio` | string | 否 | `16:9` / `9:16` / `1:1` / `4:3` / `21:9` / `adaptive` 等 |
| `duration` | int | 否 | 时长（秒）。`-1` 或省略 = 智能选择 |
| `seed` | int | 否 | 随机种子，默认 `-1` |
| `camera_fixed` | bool | 否 | 固定镜头（部分模型支持） |
| `watermark` | bool | 否 | 是否加水印，默认 `false` |
| `images` | array | 否 | 图片 URL 数组（首帧/尾帧/参考图，按 content.role 区分） |
| `metadata` | object | 否 | 扩展参数（`generate_audio`、`callback_url`、`service_tier` 等） |

`content[]` 元素：

| 字段 | 类型 | 说明 |
|---|---|---|
| `type` | string | `text` / `image_url` / `video_url` / `audio_url` |
| `text` | string | type=text 时的文本 |
| `image_url.url` | string | 图片 URL，支持 `http(s)://` 或 `data:image/…;base64,…` |
| `video_url.url` | string | 参考视频 URL |
| `audio_url.url` | string | 参考音频 URL |
| `role` | string | `first_frame` / `last_frame` / `reference_image` / `reference_video` / `reference_audio` |

**请求示例（文生视频）**

```json
{
  "model": "doubao-seedance-1.5-pro",
  "prompt": "小猫对着镜头打哈欠；视频字幕：猫咪觉得很无聊，一直在打哈欠",
  "content": [
    { "type": "text", "text": "小猫对着镜头打哈欠；视频字幕：猫咪觉得很无聊，一直在打哈欠" }
  ],
  "resolution": "720p",
  "ratio": "16:9",
  "duration": 5,
  "seed": 11,
  "camera_fixed": false,
  "watermark": true
}
```

**请求示例（首帧图生视频）**

```json
{
  "model": "doubao-seedance-2.5",
  "prompt": "城市夜景延时摄影",
  "images": ["https://cdn.example.com/seed.png"],
  "content": [
    { "type": "image_url", "image_url": { "url": "https://cdn.example.com/seed.png" }, "role": "first_frame" },
    { "type": "text", "text": "城市夜景延时摄影" }
  ],
  "resolution": "1080p",
  "duration": 6
}
```

**响应（200）**

```json
{
  "id": "cgt-20260917160000-abc123",
  "object": "video",
  "model": "doubao-seedance-1.5-pro",
  "status": "queued",
  "created_at": 1758000000,
  "progress": "0%"
}
```

> ⚠️ 首帧/尾帧/全模态参考三种模式**互斥**，不可混用（如同时给首帧图和参考图）。
> 混用时上游会拒绝，错误经平台透传为 4xx/5xx。

### 4.2 查询视频任务

```http
GET /v1/videos/{task_id}
```

**响应（200）**

```json
{
  "id": "cgt-20260917160000-abc123",
  "object": "video",
  "model": "doubao-seedance-1.5-pro",
  "status": "succeeded",
  "created_at": 1758000000,
  "completed_at": 1758000063,
  "progress": "100%",
  "metadata": { "url": "https://…/out.mp4" },
  "error": null
}
```

`status` 取值：`queued` / `running` / `succeeded` / `failed` / `cancelled` / `expired`。

失败时：

```json
{
  "id": "cgt-…",
  "status": "failed",
  "error": { "code": "InvalidArgument", "message": "resolution 不支持" }
}
```

### 4.3 下载视频内容

```http
GET /v1/videos/{task_id}/content
```

返回视频二进制流（`video/mp4`）。任务未完成时返回错误。

### 4.4 取消任务

```http
DELETE /v1/contents/generations/tasks/{task_id}
```

- `queued` 状态 → 取消成功
- `succeeded` / `failed` / `expired` → 删除记录
- `running` / `cancelled` → **上游不支持**，返回错误

### 4.5 任务列表

```http
GET /v1/contents/generations/tasks?status=queued&page_num=1&page_size=20
```

> 本接口查的是**你自己的本地任务记录**，不是上游共享账号的任务。

| 参数 | 说明 |
|---|---|
| `status` | `queued` / `running` / `succeeded` / `failed` / `cancelled` / `expired` |
| `page_num` | 默认 1，上限 500 |
| `page_size` | 默认 20，上限 500 |

## 5. 字幕擦除

### 5.1 创建擦除任务

```http
POST /v1/videos/subtitle-erase/tasks
```

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `model` | string | 是 | 固定 `cii-subtitle-erase` |
| `prompt` | string | 否 | 描述，如 `remove subtitles` |
| `metadata.video_url` | string | 是 | 待处理视频的公网 URL |

**请求示例**

```json
{
  "model": "cii-subtitle-erase",
  "prompt": "remove subtitles",
  "metadata": {
    "video_url": "https://…/source.mp4"
  }
}
```

> `video_url` 也支持嵌套形态 `{"video_url": {"url": "..."}}`，平台会自动提取。
> 缺失或为空字符串 → 400。

**响应（200）**

```json
{ "id": "task_xxx", "status": "queued", "created_at": 1758000000 }
```

### 5.2 查询擦除任务

```http
GET /v1/videos/subtitle-erase/tasks/{task_id}
```

**响应（200）**

```json
{
  "id": "task_xxx",
  "status": "completed",
  "metadata": { "url": "https://…/no_subtitle.mp4" },
  "created_at": 1758000000,
  "finished_at": 1758000062,
  "expires_at": 1758086400
}
```

`status` 取值：`running` / `completed` / `failed`。

> 计费按 `finished_at - created_at` 实际秒数结算，**提交时不预扣**。

## 6. 素材组管理

### 6.1 创建素材组

```http
POST /v1/asset-groups
```

```json
{ "Name": "我的素材组", "Description": "用于存放视频生成的参考图片素材" }
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `Name` | string | 是 | 名称，≤255 字符，不能为空 |
| `Description` | string | 否 | 描述 |

**响应（200）**

```json
{
  "id": "group-20260907145308-xntbl",
  "name": "我的素材组",
  "description": "用于存放视频生成的参考图片素材",
  "group_type": "AIGC",
  "created_at": 1757000000,
  "updated_at": 1757000000
}
```

### 6.2 素材组列表

```http
GET /v1/asset-groups?page_num=1&page_size=20
```

**响应（200）**

```json
{
  "items": [{
    "id": "group-20260907145308-xntbl",
    "name": "我的素材组",
    "description": "…",
    "group_type": "AIGC",
    "created_at": 1757000000,
    "updated_at": 1757000000
  }],
  "total": 1,
  "page_num": 1,
  "page_size": 20
}
```

### 6.3 素材组详情

```http
GET /v1/asset-groups/{group_id}
```

### 6.4 修改素材组

```http
PUT /v1/asset-groups/{group_id}
```

```json
{ "Name": "我的素材组22", "Description": "新描述" }
```

- `Name` 与 `Description` **至少传一个**，两个都空 → `400`
- 只传 `Name` 则只改名称

### 6.5 删除素材组

```http
DELETE /v1/asset-groups/{group_id}
```

**响应（200）**

```json
{ "id": "group-xxx", "status": "deleted", "upstream_error": null }
```

- 组内还有素材时会返回 **409**（请先删除组内素材）
- `upstream_error` 非空表示本地已删除但上游同步失败，可据此对账

## 8. 真人审核（Visual Validate）

用于上传真人素材前的实名/活体认证。认证通过后平台会自动创建一个素材组，
你往该组里传真人素材即可。

### 8.1 创建认证会话

```http
POST /v1/visual-validate/sessions
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `CallbackURL` | string | 是 | 认证结束后的跳转地址（浏览器打开） |
| `ProjectName` | string | 否 | 默认 `default` |

**响应（200）**

```json
{
  "BytedToken": "…",
  "H5Link": "https://ark.volcengine.com/…",
  "CallbackURL": "https://your-app.example.com/done"
}
```

| 字段 | 说明 |
|---|---|
| `H5Link` | 发给终端用户在浏览器/WebView 打开；**一次性**，用后失效 |
| `BytedToken` | 凭证，**30 分钟有效**，且仅可认证一次 |

> H5Link 可加 `lng` 参数指定语言：`zh`（默认）/ `en` / `zh-Hant`。

### 8.2 查询会话

```http
GET /v1/visual-validate/sessions            # 列表（仅本人）
GET /v1/visual-validate/sessions/{session_id}  # 详情
```

### 8.3 拉取认证结果

```http
POST /v1/visual-validate/results
```

```json
{ "BytedToken": "…" }
```

**响应（200）**

```json
{ "GroupId": "group-20260331145705-xxxxx" }
```

拿到 `GroupId` 后，即可按 §7 往该素材组上传真人素材。

### 8.4 回调

终端用户完成认证后，浏览器会跳转到：

```
<CallbackURL>?bytedToken=…&resultCode=10000&algorithmBaseRespCode=0&reqMeasureInfoValue=1&verify_type=real_time
```

| 参数 | 说明 |
|---|---|
| `resultCode` | **10000 = 认证成功**，其它为失败 |
| `algorithmBaseRespCode` | 服务端子错误码 |
| `reqMeasureInfoValue` | 是否计费（0 不计费 / 1 计费）；当前限时免费 |
| `verify_type` | 固定 `real_time` |

> 若把 `CallbackURL` 填成平台自身的
> `GET /v1/visual-validate/callback?session=<id>&sign=<token>`，
> 平台会在认证成功后**自动**拉取结果并注册素材组，无需你手动调 `/results`。

### 8.5 推荐接入流程

```
1. POST /v1/visual-validate/sessions  → 拿 H5Link + BytedToken
2. 把 H5Link 给终端用户打开（iframe / WebView）
3. 用户完成认证 → 浏览器跳转你的 CallbackURL（带 resultCode）
4. 你轮询 GET /v1/visual-validate/sessions/{id}，等 status=success
5. 取返回的 group_id，POST /v1/asset-groups/{group_id}/assets 传真人素材
```

## 9. 对话补全

### 9.1 OpenAI 风格

```http
POST /v1/chat/completions
```


## 10. 版本差异说明：比对实测与当前实现

apifox 实测文档里记录的响应是**上游方舟透传**形态：

```json
{
  "ResponseMetadata": {"RequestId": "…", "Action": "CreateAssetGroup", "Service": "ark"},
  "Result": { "Id": "group-20260907145308-xntbl" }
}
```

而当前源码（`controller/asset.go`）已改为**本地归一化**形态：

```json
{ "id": "group-20260907145308-xntbl", "name": "…", "created_at": 1757000000 }
```

| 维度 | 上游透传（旧/直连） | 本地归一化（当前实现） |
|---|---|---|
| 字段命名 | PascalCase（`Id` / `Name`） | snake_case（`id` / `name`） |
| 包裹层 | `ResponseMetadata` + `Result` | 无包裹 |
| 时间格式 | ISO8601 字符串（`2026-09-07T14:53:09Z`） | Unix 秒（int64） |
| 列表结构 | `Result.Items` + `TotalCount` | `items` + `total` + `page_num` |
| 数据归属 | 上游共享账号 | 按 `user_id` 隔离的本地表 |

**如何判断你连的是哪种**：调一次 `GET /v1/asset-groups`，
若返回含 `ResponseMetadata` 即为透传形态，字段按实测文档解析；
若返回 `items` 即为归一化形态，按本文档解析。

**已知不一致项（待平台方确认）**：

1. 实测的 `GET /v1/asset-groups/{gid}/assets`（素材列表）返回的 `Items[0]` 里是
   `Description` / `GroupType` 等**素材组**字段，而非素材字段。
   疑似接口返回了错误结构，自动化测试脚本用例 `AS-02` 会专门检出并告警。
2. 实测用 `POST /v1/videos/generations`，而源码注册的是
   `POST /v1/video/generations`（单数）与 `POST /v1/videos`。
   脚本用例 `VR-01`~`VR-03` 会探测三者可用性。

## 11. 最佳实践

### 11.1 视频生成

- 先用 `duration: 5` + `720p` 做低成本验证，通过后再上 1080p/4K
- 首帧图建议 ≤ 5MB，格式 jpg/png
- 轮询间隔 ≥ 5s，避免打满限流
- 保存返回的 `id`，它是你后续查询/下载的唯一凭证

### 11.2 素材

- `image_url` 必须是**公网可访问**的 URL，上游拉取不到会失败
- 素材组非空时不能直接删，先删素材
- 关注删除响应里的 `upstream_error`，非空说明上游残留

### 11.3 计费

- 视频按实际生成时长计费，`duration` 只是期望值，实际以上游返回为准
- 字幕擦除按实际处理秒数计费
- 用 `GET /api/log/token` 对账，字段 `quota` 即真实扣除的积分
- 发现扣费异常，先核对模型的 ModelRatio 与分组倍率配置

### 11.4 限流与重试

- 触发 `429` 时按 `Retry-After` 退避重试
- `5xx` 可重试，`4xx` 不要重试（参数问题）
- 视频生成不要并发过高，建议单账号 ≤ 3 路

## 12. 常见问题

**Q：返回 404，但文档说有这个接口？**
A：部分视频路由有单复数差异，试试 §4.1 列出的别名；或确认部署版本。

**Q：`model` 填中文名（如「Claude-Opus-4.8」）报未知模型？**
A：`model` 必须填 **model 参数值**（如 `T-C-3-hq`、`doubao-seedance-2.5`），
不是展示名。完整对照见定价表 E 列。

**Q：视频任务一直 queued 不推进？**
A：上游排队或渠道不可用。等 5–10 分钟；持续 queued 请联系平台方检查渠道状态。

**Q：为什么扣费和定价表对不上？**
A：定价表是渠道报价参考，平台实际按 ModelRatio 配置扣 quota。
可先用测试脚本（`tests/e2e/newapi_e2e.py`）跑一次计费核对，
它会给出实际 quota 与按定价表复算值的偏差百分比。

**Q：素材列表返回的是组的信息？**
A：这是已知问题，见 §10。脚本用例 `AS-02` 会自动检出。
