现在我已经拿到了完整的计费信息。根据官方文档，**Seedance 并没有从"按 token"全面改为"按秒"**——你的印象是对的，只是你可能混淆了两条产品线：

### 情况其实是这样

**火山方舟（Ark）上的 Seedance API 模型（`doubao-seedance-*`）仍然按 token 计费**，没有改为按秒：

| 模型                                            | 计费方式                               | 单价（在线推理）            |
| ----------------------------------------------- | -------------------------------------- | --------------------------- |
| `doubao-seedance-1.0-pro`                       | 按 token                               | 15 元/百万 token            |
| `doubao-seedance-1.0-pro-fast`                  | 按 token                               | 4.20 元/百万 token          |
| `doubao-seedance-2.0` / `2.0-fast` / `2.0-mini` | 按 token（区分分辨率、是否含视频输入） | 14~51 元/百万 token（原价） |
| `doubao-seedance-2.5`                           | 按 token（区分分辨率、是否含视频输入） | 42~77 元/百万 token         |

token 用量公式为：`(输入视频时长 + 输出视频时长) × 输出宽 × 输出高 × 输出帧率 / 1024`。由于这个公式本质上是"时长×分辨率×帧率"的换算，**按 token 计费可以等价折算成"元/秒"**（官方价格示例里就给了折算值，例如 seedance-2.0 在 720p 下约 0.99 元/秒、seedance-2.5 在 720p 下约 1.51 元/秒），所以对外宣传时有时会直接说"元/秒"方便直观理解，但底层计费单位仍是 token（[模型价格](https://docs.volcengine.com/docs/82379/1544106)）。

**即梦 AI（视觉智能产品线）上的视频生成能力才是真正按秒计费**，这是另一条面向 C 端/可视化场景的产品线，API 不同：

| API                        | 计费方式 | 价格       |
| -------------------------- | -------- | ---------- |
| 即梦 AI-视频生成 3.0 Pro   | 按时长   | 1 元/秒    |
| 即梦 AI-视频生成 3.0 1080p | 按时长   | 0.63 元/秒 |
| 即梦 AI-视频生成 3.0 720P  | 按时长   | 0.28 元/秒 |
| 即梦 AI-视频生成 S2.0 Pro  | 按时长   | 0.65 元/秒 |
| 动作模仿                   | 按时长   | 0.5 元/秒  |
| 数字人快速模式             | 按时长   | 1 元/秒    |

（[即梦AI-视频生成计费说明](https://docs.volcengine.com/docs/85621/1544715)）

### 为什么你会感觉"改成按秒了"

可能的原因：
1. **产品线混淆**：你早期在方舟控制台/API 调用 Seedance 2.0（按 token），后来看到的是即梦 AI 视觉产品页（按秒），两者底层模型同源但计费口径不同；
2. **折算价格的展示口径**：方舟文档最近在价格示例里开始直接给出"元/秒"的折算值（如 seedance-2.0-mini 限时优惠后"最低降至约 0.2 元/秒"），看起来像改成按秒，但底层仍走 token 结算（[模型价格](https://docs.volcengine.com/docs/82379/1544106)）；
3. **剧创平台**：剧创产品里 Seedance 2.0/2.5 是按"积分/秒"计费（[套餐说明](https://docs.volcengine.com/docs/87744/2272027)），也是按时长口径。

**总结**：你早期在方舟 API 上用的 Seedance 按 token 计费的模式没有变；按秒计费出现在即梦 AI 视觉产品线和剧创平台上。最新价格以控制台实际接入为准。
